# محصولات فروشگاه صنوبر

۹۹ محصول واقعی در دسته‌بندی‌های زیر:

## دسته‌بندی محصولات

### تشک (۷۵ محصول)
- **تشک دو نفره 200×180**: ۱۵ مدل (کامل طبی، طبی فنری، فنری)
- **تشک دو نفره 200×160**: ۱۵ مدل
- **تشک یک و نیم نفره 200×120**: ۱۵ مدل
- **تشک یک نفره (جوان) 200×90**: ۱۵ مدل
- **تشک نوجوان 180×80**: ۱۵ مدل

### سرویس خواب (۹ مدل)
ستایش، هیلدا، نوبل، نئو کلاسیک، آرتا، بیسکوییتی، صوفیا، آتنا، یونیک

### تخت خواب (۲ مدل)
- تخت دو نفره چستر کد 402
- تخت دو نفره تمام پارچه کد 401

### کالای خواب (۱۳ محصول)
- **محافظ تشک ضد آب**: ۵ سایز (۱۸۰×۸۰ تا ۲۰۰×۱۸۰)
- **سرویس روتختی ۶ تیکه**: ۳ کد
- **بالش**: تخت، طبی، پر قو
- **لحاف تشکی**

## روش وارد کردن محصولات در وردپرس

### ۱۠️⃣ دانلود فایل‌های CSV
دو فایل موجود است:
- `products-part1.csv` (۵۰ محصول اول)
- `products-part2.csv` (۴۹ محصول بعدی)

### ۲۠️⃣ پیش‌نیازها
قبل از import، مطمئن شو:
- وردپرس نصب شده است
- افزونه **WooCommerce** فعال است

### ۳۠️⃣ وارد کردن از پنل مدیریت

مراحل وارد کردن CSV:

1. وارد پنل مدیریت وردپرس شو
2. برو: **محصولات ← همه محصولات ← وردکردن (Import)**
3. یا مستقیم: `wp-admin/edit.php?post_type=product&page=product_importer`
4. روی دکمه **انتخاب فایل** کلیک کن و `products-part1.csv` رو انتخاب کن
5. در مرحله بعد، فیلدها را متناظرسازی کن (ووکامرس خودکار این کار را انجام می‌دهد)
6. **اجرای واردکردن** را بزن
7. بعد از اتمام، همین کار را برای `products-part2.csv` تکرار کن

### ۴۠️⃣ بعد از واردکردن

- دسته‌بندی‌ها خودکار ساخته می‌شوند
- تصاویر را باید دستی آپلود کنی یا از منبع اصلی انتقال بدی
- ویژگی‌های محصولات (سایز، نوع، گارانتی) در پنل **محصولات ← ویژگی‌ها** قابل تنظیم هستند

## فیلدهای موجود در CSV

| فیلد | توضیح |
|------|--------|
| `ID` | شناسه یکتا |
| `Type` | نوع محصول (simple) |
| `SKU` | کد محصول |
| `Name` | نام محصول |
| `Published` | منتشر شده (۱ = بله) |
| `Is featured?` | محصول ویژه (۱ = بله) |
| `Visibility in catalog` | قابلیت رویت |
| `Short description` | توضیحات کوتاه |
| `Description` | توضیحات کامل |
| `Regular price` | قیمت عادی (تومان) |
| `Sale price` | قیمت حراج |
| `Categories` | دسته‌بندی‌ها |
| `Tags` | برچسب‌ها |
| `Attribute 1-3` | ویژگی‌ها (سایز، نوع، گارانتی) |

## راه جایگزین: استفاده از REST API

اگر می‌خواهی محصولات رو به صورت خودکار اضافه کنی:

```php
// از REST API ووکامرس استفاده کن:
POST /wp-json/wc/v3/products
```

فایل `products.json` را برای این کار فراهم کردم.
